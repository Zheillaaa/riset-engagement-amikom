Kebijakan Privasi

Terakhir diperbarui: 10 Oktober 2026

Riset Keterlibatan Amikom merupakan prototipe untuk penelitian akademik mengenai engagement audiens pada konten media sosial.

Data yang Diproses

Jika aplikasi digunakan, data yang diproses akan bergantung pada izin API yang disetujui dan otorisasi pengguna. Aplikasi direncanakan untuk mengakses informasi profil dan video yang diizinkan melalui API resmi.

Tujuan Penggunaan

Data digunakan untuk analisis akademik mengenai konten dan interaksi audiens, bukan untuk menjual data pribadi.

Penyimpanan dan Keamanan

Data yang diperoleh harus dibatasi pada kebutuhan penelitian, disimpan secara aman, dan hanya diakses oleh pihak yang berwenang. Kredensial serta token API tidak boleh dipublikasikan.

Pihak Ketiga

Akses melalui layanan pihak ketiga tunduk pada ketentuan dan kebijakan privasi penyedia layanan tersebut.

Perubahan Kebijakan

Kebijakan ini akan diperbarui jika praktik pemrosesan data aplikasi berubah.
